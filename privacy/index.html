개인정보처리방침

윙글 키보드 (Wingul Keyboard)

본 개인정보처리방침은 윙글 키보드(이하 '앱')가 사용자의 개인정보를 어떻게 처리하고 보호하는지 설명합니다. 앱은 사용자의 프라이버시를 최우선으로 생각하며, 구글 플레이 스토어의 정책 및 관련 법령을 준수합니다.

1. 수집하는 데이터 및 처리 원칙

앱은 서비스의 핵심 기능을 안전하게 제공하기 위해 최소한의 데이터만을 처리합니다.

  • 입력 데이터 보호 (핵심): 사용자가 입력하는 모든 텍스트(문장, 비밀번호, 신용카드 번호 등)는 기기 내에서 실시간으로 처리된 후 즉시 삭제되거나 기기에만 머무르며, 어떠한 경우에도 외부 서버로 전송되지 않습니다.
  • 사용자 계정 및 동기화 데이터: 사용자가 로그인을 선택할 경우, 계정 식별을 위해 이메일 주소 및 고유 식별값(UID)을 수집합니다. 또한, 사용자가 설정한 키보드 테마 및 설정값은 클라우드 동기화(Firebase)를 통해 안전하게 서버에 저장되어 기기 변경 시에도 복구가 가능합니다.
  • 클립보드 및 메모 데이터: 사용자의 편의를 위해 제공되는 클립보드 히스토리 및 퀵메모 데이터는 사용자의 기기에만 로컬로 저장됩니다. 사용자는 언제든지 이 데이터를 직접 삭제할 수 있습니다.
  • 분석 및 성능 데이터: 앱의 서비스 개선과 오류 수정을 위해 Firebase Analytics 및 Crashlytics를 사용하며, 이 과정에서 광고 ID(AD_ID) 및 기기 정보가 수집될 수 있습니다.

2. 민감한 권한 사용 안내

앱은 서비스 제공을 위해 최소한의 권한을 요구하며, 수집된 정보는 명시된 기능 외에는 절대 사용되지 않습니다.

  • 기기 내 사진 및 미디어 접근 권한 (READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE): 스크린샷 자동 클립보드 저장, 키보드 테마 개인화(배경 사진 설정), 이미지 공유 기능을 위해 사용됩니다.
    중요: 불러온 이미지 데이터는 오직 사용자의 기기 내에서만 처리되며, 별도의 승인 없이 외부 서버로 업로드되지 않습니다.
  • 오디오 녹음 권한 (RECORD_AUDIO): 사용자가 음성 인식 입력 기능을 사용할 때 음성을 텍스트로 변환하기 위해 사용되며, 텍스트 변환 즉시 파기됩니다.
  • 인터넷 접근 권한: 클라우드 기반 설정/테마 동기화, 앱 업데이트 확인, 폰트 리소스 다운로드를 위해 사용됩니다.

3. 데이터 제3자 제공 및 위탁 (국외 이전 포함)

앱은 사용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만, 안정적인 서비스 운영을 위해 아래와 같이 전문 업체에 처리를 위탁하고 있습니다.

  • 수탁자: Google LLC (Firebase 서비스)
  • 위탁 업무: 사용자 계정 인증, 설정 데이터의 클라우드 저장 및 동기화, 앱 사용 통계 분석.
  • 국외 이전: 사용자의 계정 및 설정 데이터는 구글의 보안 표준에 따라 미국 등 해외 서버에 저장될 수 있으며, 이는 전송 시 암호화되어 안전하게 보호됩니다.

4. 데이터 보안 조치

  • 입력 데이터 로컬 처리: 키보드의 핵심 타이핑 로직은 오프라인에서도 작동하며, 민감한 입력 값은 네트워크를 타지 않습니다.
  • 암호화 저장: 기기에 저장되는 설정값이나 클립보드 데이터는 안드로이드 시스템의 안전한 로컬 저장소에 저장됩니다. 서버로 전송되는 동기화 데이터 역시 SSL/TLS 암호화 통신을 통해 보호됩니다.
  • 사용자 통제권: 사용자는 앱 내 설정 또는 개발자 문의를 통해 언제든 자신의 계정과 저장된 동기화 데이터를 삭제 요청할 수 있습니다.
